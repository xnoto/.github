# Contributing

Thanks for contributing to an xnoto project.

Before opening a pull request:

1. Read the target repository's `README`, `CONTRIBUTING`, and `AGENTS.md` files, if present.
2. For substantial changes, open or reference an issue or discussion first so the approach is agreed.
3. Keep each pull request focused on one concern and avoid unrelated formatting or dependency churn.
4. Run the validation documented by the target repository, and report what was run and any limitations in the pull request.
5. Do not include credentials, tokens, private keys, decrypted secrets, machine-specific private data, or generated state in issues or pull requests.

Repository-specific instructions and contribution requirements override this default.
